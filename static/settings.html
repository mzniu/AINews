系统配置

管理 AI 模型与资讯爬取参数。爬取 Worker 默认内嵌在 web_server 中运行（INGESTION_WORKER_MODE=embedded）。

🗣️ 语言模型

用于文章摘要、评分 AI 评语、搜索词生成等文本任务。

👁️ 视觉模型

用于后续图片内容理解、配图筛选与水印检测等视觉分析。

模型配置保存在 config/models.local.yaml（不提交 Git）。

标题生成提示词

控制主标题怎么写。默认已改为「事实抓眼」：不强制突发！/炸裂！，并禁止夸张、误导。修改后立即作用于主页、资讯库与 GitHub 成片。网友锐评、副标题等其余段落仍走内置方法论。

覆盖项保存在 config/content_prompts.local.yaml（不提交 Git）。

评分风格预设

选择适合账号定位的评分模型。预设会调整各维度权重与等级分数线，入库文章将按新规则重新定级（已有文章需手动批量重评）。

维度权重

合计 100%

各维度原始分 0–10，乘以权重后汇总为 0–100 分。保存时会自动归一化为 100%。

等级分数线

规则总分达到对应分数线即定为该等级（须满足 S > A > B > C）。

覆盖项保存在 config/article_scoring.local.yaml。修改后可用 python scripts/backfill_article_scores.py 批量重评。

配图评分预设

调整视觉模型评估配图时的维度权重与等级线。用于资讯库「评估配图」与自动勾选主画面，修改后需重新评估配图才会生效。

维度权重

合计 100%

各维度原始分 0–10，乘以权重后汇总为 0–100 分（另含横图/动图加减分）。保存时会自动归一化为 100%。

等级分数线

配图总分达到对应分数线即定为该等级（须满足 A > B > C）。

动图加成

短视频主画面优先动图。开启后，GIF 会在规则分上大幅加分，更容易进入自动勾选。

关闭时 GIF / 动画 WebP 仍有默认动图加成（+8）。开启后 GIF 改为 +25 分。修改后需重新评估配图才会生效。

覆盖项保存在 config/image_scoring.local.yaml。修改后可用 python scripts/backfill_image_scores.py 批量重评配图。

成片模板

视频和封面共用一套模板、同一分辨率。封面不写摘要，其余版式与成片一致。自动出片使用系统默认；主页生成和重新出片可以另选。

TopHub 热榜雷达

通过榜眼数据 API 拉取多个 AI 向热榜，用于文章规则评分中的「热榜雷达」维度。默认定时每天 8:00 抓取一次；手动刷新见 热榜雷达页。

—

热榜自动发现

热榜刷新后，将排名靠前且尚未入库的链接自动加入爬取队列（仅匹配已配置域名的来源，如 IT之家、36氪）。关闭后仅做匹配评分，不会触发新文章抓取。

热榜节点

每个节点对应 TopHub 的一个 hashid。基础模板见 config/hot_radar.yaml。

API Key 与覆盖项保存在 config/hot_radar.local.yaml（不提交 Git）。也可设置环境变量 TOPHUB_ACCESS_KEY。

Token 用量
