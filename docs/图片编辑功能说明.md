# 图片编辑功能说明

## 📋 功能概述

为本地上传的图片提供在线编辑功能，支持去水印、旋转、翻转等操作。

---

## ✨ 核心功能

### 1. 编辑入口
- **位置**：已上传图片的缩略图右上角
- **触发方式**：鼠标悬停时显示"🛠️"按钮
- **操作**：点击按钮打开图片编辑器

### 2. 图片编辑器功能

#### 2.1 框选水印
- 点击"✏️ 框选水印"按钮进入框选模式
- 用鼠标在图片上框选需要去除的水印区域
- 可框选多个区域

#### 2.2 去除水印
- 框选完成后，点击"🧹 去除水印"按钮
- 系统自动处理并显示结果
- 处理后的图片会替换原图显示

#### 2.3 旋转图片
- 点击"🔄 旋转"按钮
- 每次顺时针旋转 90°

#### 2.4 翻转图片
- 点击"↔️ 翻转"按钮
- 水平翻转图片

#### 2.5 保存修改
- 编辑完成后点击"💾 保存修改"
- 确认后替换原文件
- 选择区域的预览图同步更新

## 🎯 使用流程

### 场景一：单张图片去水印

```
1. 上传本地图片
   ↓
2. 图片出现在选择区域
   ↓
3. 鼠标悬停在图片上，显示"🛠️"按钮
   ↓
4. 点击"🛠️"打开编辑器
   ↓
5. 点击"框选水印"，用鼠标框选水印
   ↓
6. 点击"去除水印"，等待处理完成
   ↓
7. 点击"保存修改"，确认替换
   ↓
8. 完成！图片已更新为去水印版本
```

### 场景二：批量编辑多张图片

```
1. 上传多张需要编辑的图片
   ↓
2. 依次点击每张图片的"🛠️"按钮
   ↓
3. 对每张图片进行编辑操作
   ↓
4. 分别保存每张图片的修改
   ↓
5. 所有图片编辑完成
```

## 🔧 技术实现

### 前端实现

#### 1. UI 组件
- **编辑按钮**：绝对定位，悬停显示
- **编辑工具栏**：默认隐藏，进入编辑模式后显示
- **状态管理**：使用全局变量跟踪编辑状态

#### 2. 关键函数

```javascript
// 打开编辑器
editUploadedImage(event, imagePath)

// 进入编辑模式
enterEditMode(imagePath)

// 切换编辑模式
toggleEditMode()

// 保存编辑
saveImageEdit()

// 替换图片
replaceEditedImage(originalPath, newPath)
```

#### 3. 数据流
```
用户操作 → 调用 API → 返回处理结果 → 更新 UI
```

### 后端实现

#### API 端点

**POST /api/replace-edited-image**

替换编辑后的图片

**请求体：**
```json
{
    "original_path": "static/uploads/image.jpg",
    "new_path": "static/uploads/watermark_removed/image_clean.png"
}
```

**响应：**
```json
{
    "success": true,
    "message": "图片替换成功",
    "final_path": "static/uploads/image_edited_20260211_143025.jpg"
}
```

#### 处理逻辑

1. **验证文件存在性**
   - 检查原文件是否存在
   - 检查新文件是否存在

2. **生成新文件名**
   - 添加时间戳避免冲突
   - 格式：`原文件名_edited_时间戳。扩展名`

3. **文件操作（两种方案）**
   
   **方案 A（优先）：**
   - 备份原文件（.bak 后缀）
   - 复制新文件到原位置
   - 删除备份
   - 删除临时文件
   
   **方案 B（备用）：**
   - 移动新文件到独立目录
   - 删除原文件
   - 返回新路径

4. **返回结果**
   - 成功：返回最终文件路径
   - 失败：返回错误信息

### 编辑后的命名规则

- **原始文件**：保持原名
- **去水印文件**：`原文件名_clean_时间戳。扩展名`
- **编辑后文件**：`原文件名_edited_时间戳。扩展名`

## ⚠️ 注意事项

### 文件安全

1. **备份机制**
   - 替换前会自动备份原文件
   - 备份文件在处理完成后删除
   - 如发生错误会保留两个版本

2. **原子操作**
   - 文件操作使用 try-catch 包裹
   - 失败时回退到安全方案
   - 确保不会丢失数据

### 性能考虑

1. **大文件处理**
   - 建议使用合理的图片尺寸
   - 过大的图片可能导致处理缓慢

2. **并发处理**
   - 同一时间只处理一张图片
   - 避免文件冲突

## 📝 常见问题

### Q1: 编辑后的图片保存在哪里？
A: 编辑后的图片会替换原始文件，保存在原位置。

### Q2: 可以撤销编辑吗？
A: 目前不支持撤销。建议在编辑前备份重要图片。

### Q3: 编辑会影响已选择的图片吗？
A: 会的。编辑保存后，选择区域的图片会自动更新。

### Q4: 支持哪些图片格式？
A: 支持 JPG、PNG、GIF、WEBP 等常见格式。

### Q5: 编辑功能收费吗？
A: 完全免费，使用的是本地部署的去水印模型。
