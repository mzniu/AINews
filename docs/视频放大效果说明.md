# 视频放大效果功能说明

## 📋 功能概述

为生成的视频中的每张图片添加**持续缓慢放大**的视觉效果，让视频更有动感和专业感。

---

## ✨ 效果说明

### 动画流程

每张图的显示分为两个阶段：

```
1. 入场动画阶段（0-0.4 秒）
   └─ 图片从上滑入或缩放进入
   
2. 持续放大阶段（0.4 秒 - 结束）
   └─ 图片以非常缓慢的速度从 1.0 倍放大到 1.15 倍
      └─ 使用缓动曲线（先快后慢），让放大更自然
      └─ 保持中心点不变，向外均匀扩展
```

### 视觉效果

- **起始比例**：1.0 倍（原始大小）
- **结束比例**：1.15 倍（放大 15%）
- **放大速度**：非常缓慢，几乎察觉不到
- **视觉感受**：营造一种"聚焦"的感觉，让静态图片产生微妙的动感

## 🔧 技术实现

### 1. 数据层（video_service.py）

**新增方法：** `create_zoom_video_frames()`

为每张图片记录放大效果参数：
```python
frame_info = {
    "has_zoom": True,              # 标记需要放大效果
    "zoom_start_scale": 1.0,       # 起始缩放比例
    "zoom_end_scale": 1.15,        # 结束缩放比例（放大 15%）
    "zoom_center": (540, 960),     # 缩放中心点（画面中心）
    "image_position": (x, y),      # 图片位置
    "image_size": (w, h),          # 图片尺寸
    "duration": 5.0                # 显示时长（秒）
}
```

### 2. 渲染层（utils/video_utils.py）

**修改函数：** `_render_frame_animated()`

新增参数：
- `zoom_effect`: 是否启用持续放大效果
- `zoom_start_scale`: 起始缩放比例
- `zoom_end_scale`: 结束缩放比例
- `clip_duration`: 片段总时长

**核心算法：**

```python
# 计算放大阶段的进度（从 entrance_duration 到 clip_duration）
zoom_progress = (t - entrance_duration) / (clip_duration - entrance_duration)

# 使用缓动曲线让放大更自然（先快后慢）
zoom_ease = 1 - (1 - zoom_progress) ** 2

# 计算当前缩放比例
current_scale = zoom_start_scale + (zoom_end_scale - zoom_start_scale) * zoom_ease

# 计算缩放后的尺寸
scaled_w = int(target_width * current_scale)
scaled_h = int(target_height * current_scale)

# 缩放图片并保持中心点不变
scaled_img = user_img_resized.resize((scaled_w, scaled_h), Image.Resampling.LANCZOS)
new_x = paste_x + (target_width - scaled_w) // 2
new_y = final_paste_y + (target_height - scaled_h) // 2
```

### 3. 路由层（api/routes/video_routes.py）

**修改位置：** `create_animated_video()` 函数

```python
# 检查是否需要放大效果（从 frame_info 中读取）
has_zoom = img_data.get('has_zoom', False)
zoom_start = img_data.get('zoom_start_scale', 1.0)
zoom_end = img_data.get('zoom_end_scale', 1.15)

# 创建动画片段时传递放大参数
def make_frame_func(t, ..., _zoom=has_zoom, _zs=zoom_start, _ze=zoom_end):
    return _render_frame_animated(
        ...,
        zoom_effect=_zoom,
        zoom_start_scale=_zs,
        zoom_end_scale=_ze,
        clip_duration=clip_duration
    )
```

## 🎯 数学原理

### 缓动曲线选择

使用 **二次缓出（Ease Out Quad）** 曲线：
```
zoom_ease = 1 - (1 - progress)²
```

**特点：**
- 开始时变化较快
- 接近结束时变化变慢
- 符合物理世界的运动规律（如汽车刹车）
- 视觉上更自然舒适

### 时间分配

假设一个片段总时长为 5 秒：

| 时间段 | 阶段 | 内容 |
|--------|------|------|
| 0.0s - 0.4s | 入场动画 | 图片从上滑入/缩放进入 |
| 0.4s - 5.0s | 持续放大 | 从 1.0 倍缓慢放大到 1.15 倍 |

**放大速度计算：**
- 总增幅：15%
- 放大时长：4.6 秒
- 平均每秒放大：约 3.26%

## ⚙️ 配置参数

### 可调整的参数

在 `utils/video_utils.py` 中可以调整：

```python
# 默认放大参数
zoom_start_scale = 1.0      # 起始缩放比例
zoom_end_scale = 1.15       # 结束缩放比例（建议范围：1.1 - 1.2）

# 缓动曲线
zoom_ease = 1 - (1 - zoom_progress) ** 2  # 二次缓出

# 可选的其他缓动曲线：
# zoom_ease = zoom_progress               # 线性（匀速）
# zoom_ease = zoom_progress ** 2          # 二次缓入（先慢后快）
# zoom_ease = 1 - (1 - zoom_progress) ** 3 # 三次缓出（更明显的减速）
```

### 推荐配置

根据不同场景推荐不同的配置：

| 场景 | 起始比例 | 结束比例 | 缓动类型 |
|------|---------|---------|---------|
| 新闻视频 | 1.0 | 1.10 | 二次缓出 |
| 科技评测 | 1.0 | 1.15 | 二次缓出 |
| 情感故事 | 1.0 | 1.20 | 三次缓出 |
| 快节奏 | 1.0 | 1.12 | 线性 |

## ⚠️ 注意事项

### 性能考虑

1. **实时缩放计算**
   - 每帧都需要重新计算缩放比例
   - 对 CPU 有一定压力
   - 建议单片段时长不超过 10 秒

2. **内存占用**
   - 缩放后的图片会占用额外内存
   - 处理大图片时注意内存管理

### 视觉效果

1. **不要过度放大**
   - 建议最大不超过 1.2 倍
   - 否则会显得不自然
   - 可能暴露图片边缘

2. **配合其他特效**
   - 可以同时使用金粉、雪花等特效
   - 放大效果与入场动画类型无关
   - 所有入场动画都可以应用持续放大
