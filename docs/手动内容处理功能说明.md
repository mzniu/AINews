# 📝 手动内容处理功能使用说明

## 🎯 功能概述

为了解决某些网站（如 51CTO）启用反爬机制导致无法正常抓取内容的问题，新增了**手动粘贴模式**。用户可以直接粘贴文章的 HTML 源码或纯文本内容，系统会自动处理和提取关键信息。

## 🌟 主要特性

### 1. **双模式切换**
- 🤖 **自动抓取模式**：输入 URL 自动爬取（适用于无防护的网站）
- 📝 **手动粘贴模式**：粘贴内容手动处理（适用于有反爬机制的网站）

### 2. **智能内容识别**
- 自动检测内容是 HTML 格式还是纯文本
- 智能提取标题、正文、图片、视频等元素
- 支持相对路径和绝对路径的图片/视频链接

### 3. **强大的解析能力**
- **HTML 解析**：使用 BeautifulSoup 精准提取
- **文本解析**：智能识别段落和图片链接
- **去重处理**：自动去除重复图片
- **内容清洗**：清理多余空白和格式

## 🚀 使用方法

### 方式一：处理 HTML 源码

1. **复制网页源码**
   - 在浏览器中打开目标网页
   - 右键点击页面 → "查看页面源代码" (或按 F12)
   - 全选 (Ctrl+A) 并复制 (Ctrl+C) 所有 HTML 代码

2. **粘贴到工具**
   - 访问首页：http://localhost:8000/
   - 切换到 **"📝 手动粘贴"** 模式
   - 在文本框中粘贴 HTML 源码
   - 点击 **"🚀 处理内容"** 按钮

3. **查看结果**
   - 系统会自动提取标题、内容、图片
   - 显示内容预览和统计信息
   - 可以下载完整内容或继续处理

### 方式二：处理纯文本

1. **复制文本内容**
   - 在网页中直接选中文章文字
   - 复制 (Ctrl+C)

2. **粘贴处理**
   - 切换到手动粘贴模式
   - 粘贴纯文本内容
   - 系统会自动识别并提取其中的图片链接

3. **获取结果**
   - 第一行作为标题
   - 保留原始段落格式
   - 提取文本中的图片 URL

## 💡 应用场景

### ✅ 适用情况
- 网站启用了 WAF 防火墙（如 51CTO、CSDN 等）
- 需要登录才能查看的内容
- 动态加载的 SPA 应用页面
- 反爬机制严格的网站
- 快速处理已保存的 HTML 文件

### ❌ 不适用情况
- 完全可以正常抓取的简单网站
- 需要交互才能显示的内容（需先手动触发）

### 后端 API
```python
POST /api/process-manual-content

请求参数:
{
    "content": "HTML 源码或纯文本",
    "url": "可选的原始 URL"
}

返回结果:
{
    "success": true,
    "title": "文章标题",
    "content": "提取的正文内容",
    "images": [{"url": "...", "filename": "..."}],
    "videos": [{"url": "...", "type": "..."}],
    "content_type": "html|text"
}
```

### 核心处理流程

1. **内容检测**
   - 检测是否包含 HTML 标签
   - 自动选择处理方式

2. **HTML 处理**
   ```python
   - 移除干扰元素 (script, style, nav 等)
   - 提取标题 (h1, .article-title 等)
   - 提取正文 (article, .content 等)
   - 提取图片 (img 标签)
   - 提取视频 (video, iframe 标签)
   ```

3. **文本处理**
   ```python
   - 第一行作为标题
   - 保留原始格式
   - 正则提取图片 URL
   - 智能识别链接
   ```

## 🔍 常见问题

### Q1: 为什么选择手动模式？
**A:** 当自动抓取遇到反爬机制时，手动模式可以绕过所有限制，因为内容是您主动提供的。

### Q2: HTML 源码和纯文本有什么区别？
**A:** 
- **HTML 源码**：包含完整的页面结构和样式，能提取更多元数据
- **纯文本**：只有文字内容，系统会智能识别其中的链接

### Q3: 如何获得最佳效果？
**A:** 
1. 优先使用 HTML 源码（F12 复制完整代码）
2. 确保内容完整（包括图片和视频标签）
3. 如果是纯文本，尽量包含原始 URL 以便处理相对路径

### Q4: 处理失败怎么办？
**A:** 
- 检查内容是否为空
- 确认 HTML 格式是否正确
- 尝试使用纯文本模式
- 查看浏览器控制台错误信息
