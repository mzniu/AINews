# 智能动画选择功能说明

## 📋 功能概述

当生成视频时，如果选中的图片高度过大（超过屏幕高度的 70%），系统会：
1. **自动将该图片的动画改为向上滚动播放**（`scroll_up`）
2. **禁用放大效果**，避免与滚动冲突
3. 让用户可以**从上到下浏览完整内容**

---

## 🎯 设计原因

### 问题场景：
- 用户选择了**长图/高图**（如 GitHub 主页截图、网页完整截图等）
- 如果使用普通的缩放或淡入动画，图片内容会被压缩或裁剪
- 用户体验不佳，无法看清完整内容

### 解决方案：
- **检测图片高度比例**
- **自动切换为滚动动画**
- 让用户可以**从上到下浏览完整内容**

---

## 🔧 技术实现

### 1. 检测逻辑

```python
# 计算图片高度占屏幕的比例
img_height_ratio = target_h / img_height

# 如果超过 70%，使用滚动动画
if img_height_ratio > 0.7:
    anim = 'scroll_up'  # 强制使用向上滚动
```

### 2. 应用位置

#### A. 静态图片处理 - 动画选择
**文件：** `api/routes/video_routes.py`  
**行号：** 第 670-678 行

```python
# 每张图使用不同的动画（打乱后循环分配）
anim = anim_queue.pop(0)

# ⚠️ 智能动画选择：如果图片高度过大，自动使用向上滚动
img_height_ratio = target_h / img_height  # 图片高度占屏幕比例
if img_height_ratio > 0.7:  # 如果图片高度超过屏幕 70%
    anim = 'scroll_up'  # 强制使用向上滚动
    logger.info(f"片段 {idx} 检测到高图（{img_height_ratio:.1%}），自动使用 scroll_up 动画")
else:
    logger.info(f"片段 {idx} 动画类型：{anim}")
```

#### B. 静态图片处理 - 禁用放大效果
**文件：** `api/routes/video_routes.py`  
**行号：** 第 687-703 行

```python
# 检查是否需要放大效果（从 frame_info 中读取）
has_zoom = img_data.get('has_zoom', False)
zoom_start = img_data.get('zoom_start_scale', 1.0)
zoom_end = img_data.get('zoom_end_scale', 1.15)

# ⚠️ 智能调整：如果使用了 scroll_up 动画（高图），禁用放大效果
if anim == 'scroll_up':
    has_zoom = False  # 高图不使用放大效果，改为向上滚动
    logger.info(f"片段 {idx} 高图使用 scroll_up 动画，已禁用放大效果")
else:
    # 正常图片：应用放大效果
    if idx == 1 and has_zoom:
        zoom_end = min(1.48, float(zoom_end) + 0.5)
        zoom_start = max(1, float(zoom_start))
    if idx >= 2 and has_zoom:
        zoom_end = min(1.48, float(zoom_end))
        zoom_start = max(0.88, float(zoom_start) - 0.03)
    
    if has_zoom:
        logger.info(f"片段 {idx} 启用放大效果：{zoom_start} -> {zoom_end}")
```

## 📊 参数说明

### 阈值设置：70%

```python
if img_height_ratio > 0.7:  # 70% 阈值
```

**为什么是 70%？**
- **太低（如 50%）**：太多图片会被判定为高图，影响多样性
- **太高（如 90%）**：真正的高图可能不会被识别
- **70%**：平衡点，既能识别明显的高图，又不会过度干预

### 可调整性

如果需要调整阈值，修改以下数值即可：

```python
# 更敏感：50% 以上就使用滚动
if img_height_ratio > 0.5:
    anim = 'scroll_up'

# 更保守：80% 以上才使用滚动
if img_height_ratio > 0.8:
    anim = 'scroll_up'
```

## 💡 应用场景

### 适合使用滚动动画的场景：
1. ✅ GitHub 仓库主页截图
2. ✅ 博客文章完整截图
3. ✅ 新闻网页长截图
4. ✅ 数据报表/图表长图
5. ✅ 社交媒体动态长截图

### 不适合的场景（会使用其他动画）：
1. ❌ 标准照片（16:9、4:3）
2. ❌ 正方形图片（1:1）
3. ❌ 横幅图片（宽屏）
4. ❌ 图标/Logo
