# 文章配图相关度评分标准（规则 + 视觉模型）

## 定位

面向 **8–12 秒 AI 快讯短视频**：运营选中文章后，从配图中挑出 **3–4 张主画面**（每张约 2–3 秒），**优先动图（GIF / 动画 WebP）**，排除章节标题图、过渡装饰图。

与 [文章选题评分](article_scoring_criteria.md) 互补：文章评分决定「值不值得做」，配图评分决定「用哪些图做短片」。

## 评分结构

- **规则预筛**：过滤过小图、logo、章节标题 URL 等
- **动图加成**：GIF / 动画 WebP 自动 **+8** 分
- **视觉模型评分**：使用资讯库「模型设置」中当前启用的视觉模型
- **触发方式**：资讯库选文后，手动点击「评估配图」

## 维度与权重（v1.2）

| 维度 | 权重 | 说明 |
|------|------|------|
| 主题相关度 | 30% | 图中主体/场景与文章标题、摘要、关键词的匹配程度 |
| 信息价值 | 18% | 产品截图、数据图表、现场图 > 纯装饰图 |
| **短视频主画面** | **18%** | **是否适合 2–3 秒一镜的主画面**（非标题卡/过渡图） |
| 画质可用性 | 12% | 清晰度、分辨率、图中文字可读性 |
| 人物突出度 | 10% | 重要/争议人物是否清晰出镜 |
| 封面适配度 | 5% | 缩略图参考（权重较低） |
| 合规安全 | 7% | 水印、二维码、广告条、纯 logo |

## 横图优先（规则）

- 宽/高 ≥ 1.25：加 **+5** 分
- 宽/高 ≤ 1.0（竖图）：扣 **-5** 分

## 动图优先（规则）

- GIF 或多帧动画 WebP：加 **+8** 分
- 同分时排序：动图 → 主画面适配度 → 人物突出度 → 横图

## 扣分项

| 情形 | 默认扣分 |
|------|----------|
| 章节/小节标题图 | -25 |
| 过渡/装饰分隔图 | -20 |
| 明显水印/二维码 | -15 |
| 纯 logo/图标 | -20 |
| 广告/营销横幅 | -15 |
| 与 AI 垂类明显无关 | -10 |
| 近重复图 | -15 |
| 竖图（宽≤高） | -5 |

## 等级与自动勾选

| 等级 | 分数 | 建议 |
|------|------|------|
| A | ≥80 | 首选主画面，准备主页时**自动勾选** |
| B | 60–79 | 可用；若无 A 级则**回退自动勾选** |
| C | 40–59 | 置底展示 |
| D | <40 | 不推荐 |

自动勾选上限 **4 张**（`auto_select.max_count`），对应 8–12 秒短片常用素材量。

## 排序

按总分降序 → 等级 → **动图** → 主画面适配度 → 人物突出度 → 横图 → 来源 → 原顺序。

## 同题配图

若文章属于某个 Story，评估时会一并纳入其他来源文章的配图（`StoryAsset`），但在**当前被选文章**的语境下打分。

## 配置

权重与阈值见 `config/image_scoring.yaml`（`scorer_version: "1.2"`）。

## API

- `POST /api/ingestion/articles/{id}/score-images` — body: `{ "force": false, "include_story_images": true }`
- `POST /api/ingestion/articles/{id}/prepare-video?auto_select=true` — 按评分排序并自动勾选最多 4 张

主页生成会携带 `relevance_grade`、`flash_fit_score`、`is_animated` 等字段，在选图区展示评分标签供参考。

## 脚本

```bash
python scripts/backfill_image_scores.py
python scripts/backfill_image_scores.py --source aitnt_travel --limit 20
python scripts/backfill_image_scores.py --article-id <article_id> --force
```

## 前置条件

在「模型设置」页配置并启用视觉模型，通过连通性测试后再使用本功能。

## 水印联动

规则预筛默认开启 OpenCV 角落水印检测，与 `/api/detect-watermark` 共用 `services/image_watermark_detect.py`。
