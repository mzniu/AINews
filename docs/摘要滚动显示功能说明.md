# 摘要滚动显示功能说明

## 📋 功能概述

将视频中的摘要文字分成**3 段**，以**滚动动画**的方式依次显示，增强视频的层次感和节奏感。

---

## ✨ 效果说明

### 动画时间轴

```
0.0s - 0.4s: 图片入场动画
             └─ 图片从上滑入或缩放进入

0.4s - 1.4s: 静止阶段（无文字）
             └─ 图片完全静止，吸引注意力

1.4s - 2.2s: 第 1 段摘要淡入 + 滑入
             ├─ 从下方 50px 处滑入
             ├─ 透明度从 0 到 100%
             └─ 使用缓入曲线（从慢到快）

2.2s - 3.0s: 第 2 段摘要淡入 + 滑入
             ├─ 第 1 段保持显示
             ├─ 第 2 段从下方滑入
             └─ 同样的缓入效果

3.0s - 3.8s: 第 3 段摘要淡入 + 滑入
             ├─ 第 1、2 段保持显示
             ├─ 第 3 段从下方滑入
             └─ 3 段全部显示完成

3.8s - 结束：3 段摘要同时显示
             └─ 直到下一张图片开始
```

### 视觉效果

- **每段间隔**：0.8 秒
- **滑动距离**：50px（从下方向上滑入）
- **透明度**：从 0% 渐变到 100%
- **缓动曲线**：二次缓入（ease-in），从慢到快
- **最终布局**：3 段垂直排列，间距适中

## 🔧 技术实现

### 1. 智能分段算法（video_routes.py）

**分段策略：**

```python
# 优先按句子分割
sentences = re.split(r'[。！？.!?]', summary_text)

if len(sentences) >= 3:
    # 平均合并成 3 段
    segment1 = sentences[:seg1_end]
    segment2 = sentences[seg1_end:seg2_end]
    segment3 = sentences[seg2_end:]
    
elif len(sentences) == 2:
    # 第 1 句为一段，第 2 句分成两段
    segment1 = sentences[0]
    segment2 = sentences[1][:mid_point]
    segment3 = sentences[1][mid_point:]
    
else:
    # 只有 1 段，按字符数平均分割
    segment1 = text[:len/3]
    segment2 = text[len/3:2*len/3]
    segment3 = text[2*len/3:]
```

**示例：**

输入摘要：
```
"人工智能正在改变世界。它应用于医疗、金融、交通等领域。未来将有更多突破。"
```

自动分段结果：
```
第 1 段："人工智能正在改变世界。"
第 2 段："它应用于医疗、金融、交通等领域。"
第 3 段："未来将有更多突破。"
```

### 2. 位置计算

```python
# 计算每段的高度
seg_height = sum(line_height for line in lines)

# 计算总高度
total_height = seg1_height + seg2_height + seg3_height

# 摘要起始位置（距离底部 10%）
summary_start_y = img_height * 0.9 - total_height

# 每段的 Y 坐标
current_y = summary_start_y
for each segment:
    segment_positions.append((segment_text, current_y))
    current_y += segment_height
```

### 3. 渲染逻辑（video_utils.py）

**核心算法：**

```python
scroll_start_time = entrance_duration + hold_with_text_start  # 1.4s
segment_duration = 0.8  # 每段间隔 0.8 秒

for i, (segment_text, seg_y) in enumerate(summary_segments):
    seg_start_time = scroll_start_time + i * segment_duration
    seg_progress = (t - seg_start_time) / segment_duration
    
    if t >= seg_start_time:
        # 缓入曲线
        ease = seg_progress ** 2
        
        # 透明度
        alpha = min(1.0, ease)
        
        # 滑动偏移
        slide_offset = int(50 * (1 - alpha))
        current_y = seg_y + slide_offset
        
        # 绘制这段（应用透明度）
        draw_segment(bg, segment_text, current_y, alpha)
```

## 📊 配置参数

### 可调参数

在 `utils/video_utils.py` 中可以调整：

```python
# 滚动开始时间
scroll_start_time = entrance_duration + hold_with_text_start  # 默认 1.4s

# 每段间隔时间
segment_duration = 0.8  # 默认 0.8 秒（可改为 0.6 或 1.0）

# 滑动距离
slide_distance = 50  # 默认 50px（可改为 30 或 80）

# 缓动曲线类型
ease = seg_progress ** 2  # 二次缓入
# 或：ease = seg_progress  # 线性
# 或：ease = seg_progress ** 3  # 三次缓入
```

### 推荐配置

根据不同场景：

| 场景 | 间隔时间 | 滑动距离 | 缓动类型 |
|------|---------|---------|---------|
| 快节奏 | 0.6s | 30px | 线性 |
| 标准 | 0.8s | 50px | 二次缓入 |
| 慢节奏 | 1.0s | 80px | 三次缓入 |

## ⚠️ 注意事项

### 1. 摘要长度建议

**推荐长度：**
- 最短：30 字（每段约 10 字）
- 最长：150 字（每段约 50 字）
- 最佳：60-90 字（每段 20-30 字）

**原因：**
- 太短：分段后信息量不足
- 太长：单段文字过多，影响阅读

### 2. 时间分配

**每张图片的总时长建议：**
- 最短：3.0 秒（1.4s + 0.8s×2 ≈ 3.0s）
- 推荐：4.0-6.0 秒
- 最长：不超过 10 秒

**计算方式：**
```
总时长 = 入场时间 (0.4s) + 静止 (0.8s) + 
         第 1 段 (0.8s) + 第 2 段 (0.8s) + 
         第 3 段 (0.8s) + 静持时间
```

### 3. 兼容性

**向后兼容：**
- 如果摘要无法分成 3 段，会自动降级为普通显示
- 仍然支持旧的 `summary_lines` 格式
- 可以手动关闭滚动效果（设置 `enable_summary_scroll=False`）
